# Sistema de Gestión para Taller Mecánico 

Software desarrollado en Java (NetBeans) y MySQL para administrar clientes, vehículos y reparaciones.

##  Funcionalidades
- Registro de Clientes y Vehículos.
- Gestión de órdenes de trabajo.
- Reportes en PDF (JasperReports).
- Base de datos incluida (BDMECANICA.sql).
